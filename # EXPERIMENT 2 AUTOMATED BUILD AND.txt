# EXPERIMENT 2: AUTOMATED BUILD AND DEPENDENCY MANAGEMENT USING APACHE MAVEN

## 1. AIM

To construct a standard Java project structure to manage dependencies through `pom.xml` and automate the build lifecycle, specifically compilation, unit testing and packaging.

## 2. SOFTWARE REQUIREMENTS

1. Java Development Kit (JDK)
2. Apache Maven
3. Eclipse IDE
4. JSON Simple library

## 3. PROCEDURE

### Step 1: Create a Maven Project in Eclipse

1. Open Eclipse IDE.

2. Select **File → New → Other**.

3. Select **Maven → Maven Project**.

4. Click Next.

5. Select the option to create a simple project or select an archetype, depending on the project creation procedure.

6. For the archetype method, select `maven-archetype-quickstart`.

7. Enter the following details:

   * Group ID: `Abrar`
   * Artifact ID: `Abrar`
   * Version: `0.0.1-SNAPSHOT`
   * Packaging: `jar`

8. Click Finish.

### Step 2: Create the JSON File

1. Right-click the project.
2. Select New → File.
3. Enter the filename `Student.json`.
4. Add the following content:

```json
{
    "firstname": "Mohammed",
    "lastname": "Abrar"
}
```

5. Save the file in the project root directory, alongside `pom.xml`.

### Step 3: Configure Dependencies in pom.xml

Open `pom.xml` and add the JSON Simple dependency inside the `<dependencies>` section.

```xml
<dependencies>
    <dependency>
        <groupId>junit</groupId>
        <artifactId>junit</artifactId>
        <version>3.8.1</version>
        <scope>test</scope>
    </dependency>

    <dependency>
        <groupId>com.googlecode.json-simple</groupId>
        <artifactId>json-simple</artifactId>
        <version>1.1.1</version>
        <scope>compile</scope>
    </dependency>
</dependencies>
```

### Step 4: Create the Java Class

1. Expand `src/main/java`.
2. Right-click the package `Abrar.Abrar`.
3. Select New → Class.
4. Enter the class name `ReadJSON`.
5. Select the main method option.
6. Click Finish.

### Step 5: Java Program to Read JSON Data

Save the following program as `ReadJSON.java`.

```java
package Abrar.Abrar;

import java.io.FileReader;
import java.io.IOException;

import org.json.simple.JSONObject;
import org.json.simple.parser.JSONParser;
import org.json.simple.parser.ParseException;

public class ReadJSON {

    public static void main(String[] args)
            throws IOException, ParseException {

        JSONParser jsonparser = new JSONParser();

        FileReader reader =
                new FileReader("./Student.json");

        Object obj = jsonparser.parse(reader);

        JSONObject studentobj = (JSONObject) obj;

        String fname =
                (String) studentobj.get("firstname");

        String lname =
                (String) studentobj.get("lastname");

        System.out.println("Firstname: " + fname);
        System.out.println("Lastname: " + lname);
    }
}
```

### Step 6: Execute the Java Program

1. Right-click `ReadJSON.java`.
2. Select Run As → Java Application.
3. Check the Console window.

**Expected Output:**

```text
Firstname: Mohammed
Lastname: Abrar
```

### Step 7: Verify Maven Installation

Open PowerShell and execute:

```powershell
java -version
mvn -version
```

If Maven is not recognised, download the Binary ZIP archive from:

https://maven.apache.org/download.cgi

Extract it, for example, to `C:\apache-maven`.

Configure the Windows environment variables:

* `MAVEN_HOME` = `C:\apache-maven`
* Add `%MAVEN_HOME%\bin` to the `Path` variable.

Open a new PowerShell window and verify:

```powershell
mvn -version
```

### Step 8: Compile the Project

Open PowerShell in the project directory containing `pom.xml`.

Execute:

```powershell
mvn clean compile
```

This removes the previous build output and compiles the Java source files.

### Step 9: Perform Unit Testing

Execute:

```powershell
mvn test
```

This executes the unit tests configured in the Maven project.

### Step 10: Package the Application

Execute:

```powershell
mvn package
```

This compiles, tests and packages the project into a JAR file.

The generated JAR file can be found inside:

```text
target/
```

### Step 11: Other Important Maven Commands

```powershell
mvn clean
mvn compile
mvn test
mvn package
mvn install
```

* `mvn clean` – Removes previously generated build files.
* `mvn compile` – Compiles the source code.
* `mvn test` – Executes unit tests.
* `mvn package` – Creates the JAR package.
* `mvn install` – Installs the generated package into the local Maven repository.

## 4. PROJECT STRUCTURE

```text
Abrar/
│
├── pom.xml
├── Student.json
│
├── src/
│   ├── main/
│   │   └── java/
│   │       └── Abrar/
│   │           └── Abrar/
│   │               └── ReadJSON.java
│   │
│   └── test/
│       └── java/
│
└── target/
    └── Abrar-0.0.1-SNAPSHOT.jar
```

## 5. RESULT

Thus, a standard Java project was created using Apache Maven. Dependencies were managed through `pom.xml`, JSON data was read using the JSON Simple library, and the Maven build lifecycle was demonstrated through compilation, testing and packaging.
